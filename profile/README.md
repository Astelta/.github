# Astelta

This organization serves as the central repository for backend services, infrastructure, and interactive systems built around the Astelta web novel universe. 

### Current Focus
Active development is dedicated to the **[ParkBankAPI](https://github.com/Astelta/ParkBankAPI)** – a PostgreSQL-backed REST API operating as the core engine for the in-universe economy.
